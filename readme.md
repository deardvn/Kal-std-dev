# Kalkulator Standar Deviasi & RSD - Zona Nilai Tanah (ZNT)

Aplikasi web interaktif untuk menghitung Rata-rata (Mean), Standar Deviasi (SD), dan Relatif Standar Deviasi (RSD) secara otomatis untuk kebutuhan analisis Zona Nilai Tanah (ZNT).

## 🚀 Fitur Utama
- **Hitung Otomatis**: Menghitung Mean, SD, dan RSD dengan cepat.
- **Validasi Nilai**: Indikator kelayakan sampel (RSD ≤ 25%).
- **Tampilan Interaktif**: Desain neumorphism modern dengan dukungan mode gelap (*Dark Mode*).
- **Format Rupiah**: Otomatis memformat angka input dengan pemisah ribuan.

## 🛠️ Teknologi yang Digunakan
- HTML5
- CSS3 (Neumorphism Design & Responsive)
- JavaScript (Vanilla JS)
